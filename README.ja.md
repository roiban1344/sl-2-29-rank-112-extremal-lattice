# SL₂(29) 作用をもつ112次元格子

[English](README.md)

112次元の14個の極値偶ユニモジュラー格子として提示する L112.01–L112.14 と、最小値が未決の候補 L112.15 の Gram 行列と構造化データを収録する、作業中のリポジトリです。**この版には証明を掲載していません。** 極値性・相異性・分類の証明と検証コードは順次追加します。独立した人間によるレビューは未実施です。

L112.01 には[別リポジトリの公開版 v2026-10-19.1](https://github.com/roiban1344/112-dimensional-extremal-even-unimodular-lattice/tree/v2026-10-19.1)に計算機援用証明のパッケージがあります。L112.02–L112.14 の極値性は研究計算の結果を記録したもので、この版には証明パッケージを含めていません。L112.15 の極値性は主張しません。

15件の整数 Gram 行列と構造化データを収録します。L112.01–L112.15 は各行列を識別する固定 ID です。全項目は [lattices/index.json](lattices/index.json)、形式と状態ラベルは [docs/schema.md](docs/schema.md) に記載します。

整数係数の行ベクトル x のノルム（長さの2乗）は x G xᵀ です。112次元の極値偶ユニモジュラー格子の最小ノルムは10です。Gram ファイルは `#` で始まるコメント行を除くと112行×112列で、空白区切りの10進整数です。

Python 3.11 以上の標準ライブラリだけで `python3 check/check.py` を実行できます。全ファイルのハッシュ、メタデータの整合性、対称性・正定値性・偶性・行列式1を整数演算で検査します。**この検査は最小値・相異性・群作用・分類の検証ではありません。** 全自己同型群や kissing number の主張は、このデータ版には含めません。
