# 検査から主張へ

[English](construction.md)

`code/verify/` のスクリプトは、整数行列の間の等式を検査します。このページでは、それらの等式から [STATUS.ja.md](../STATUS.ja.md) で「ここで検査可能」とした主張を導く短い議論を示します。格子は行格子とします。つまり、格子は行が基底をなす行列で与えます。外側の形式がある座標で Gram 行列 A をもつとき、その座標での基底行列 Y の Gram 行列は Y A Yᵀ です。格子 X について、X^# はその形式に関する双対です。

## B0 ⊥ B0 の中の L112.03–14

`code/verify/v2_construction.py` の関数 `check_wb2`。

b を B0 の Gram 行列（`data/Wb2/base-gram.txt`、56 × 56、det b = 29⁴⁸）とし、E = B0 ⊥ B0 とします。ℤ¹¹² の標準基底に関する E の Gram 行列は bb = diag(b, b) です。ファイル `data/Wb2/L112.XX-basis.txt` は整数行列 z を収めています。z/29 の行は、E の座標で書いた格子 L ⊂ E ⊗ ℚ の基底です。スクリプトは次を検査します。

1. **z bb ≡ 0 (mod 29)。** L の基底と E の基底の内積は (z/29) bb の成分なので、整数です。つまり **L ⊂ E^#**。
2. **z bb zᵀ ≡ 0 (mod 29²) であり、Gram 行列 z bb zᵀ / 29² は偶で行列式 1。** したがって L は偶な整格子で、**L^# = L**。
3. **よって E ⊂ L。** 双対をとると包含が逆になるので、L ⊂ E^# から E = (E^#)^# ⊂ L^# = L。
4. **指数。** E ⊂ L なので det E = [L : E]² det L。ここで det E = (det b)² = 29⁹⁶、det L = 1 なので **[L : E] = 29⁴⁸**。言い換えると、L の基底行列 z/29 について |det(z/29)| = [L : E]⁻¹、つまり |det z| = 29¹¹²⁻⁴⁸ = 29⁶⁴。スクリプトは |det z| = 29⁶⁴ も検査しますが、これは上の検査から従います。
5. **公開した行列。** U = `data/Wb2/L112.XX-lll.txt` について det U = ±1 なので、Uᵀ z / 29 の行も L の基底です。その Gram 行列 Uᵀ (z bb zᵀ / 29²) U を `lattices/L112.XX/gram.txt` と比べます。
6. **S の作用。** s₁, s₂ を `data/Wb2/base-S.txt` の 2 つの行列（b を保つ）とし、Y = Uᵀ z とします。`lattices/L112.XX/generators.txt` の最初の 2 つの生成元 g について、スクリプトは g Y = Y diag(sᵢ, sᵢ) を検査します。これは、E に対角に作用する元が、L の公開した基底を g の行が与える整数係数の結合に移すということです。したがって S は L を保ち、公開した生成元は公開した基底に関するその行列です。

スクリプトは B0 をこれ以上同定しません。検査しないことは [data/README.ja.md](../data/README.ja.md) に挙げています。

## 生成元が生成する群

`code/verify/v1_action.py`。

**厳密な部分。** スクリプトは各生成元 g について、Gram 行列 G に対し g G gᵀ = G を整数で検査します。det G = 1 なので det g = ±1 であり、g は格子の自己同型です。

**群は有限。** これらの行列が生成する群を Γ とします。Γ の元 g はすべて g G gᵀ = G を満たすので、その第 i 行 x は x G xᵀ = Gᵢᵢ を満たします。G は正定値なので、ノルムが決まった整数ベクトル x は有限個しかありません。よって Γ は有限です。

**3 を法とする還元は Γ 上で単射。** これは古典的な事実です（Minkowski 1887）。g ∈ Γ が g ≡ I (mod 3) を満たし、g ≠ I と仮定します。g の適当なべきは素数位数 p をもち、≡ I (mod 3) のままで ≠ I です。g をそれに置き換え、k ≥ 1、A ≢ 0 (mod 3) として g = I + 3ᵏ A と書きます。(I + 3ᵏ A)ᵖ = I を展開すると

  0 = p 3ᵏ A + C(p, 2) 3²ᵏ A² + … + 3ᵖᵏ Aᵖ

となります。

- p ≠ 3 なら、最初の項以外はすべて 3ᵏ⁺¹ で割り切れるので、p A ≡ 0 (mod 3)、つまり A ≡ 0 (mod 3)。
- p = 3 なら、式は 3ᵏ⁺¹ A + 3²ᵏ⁺¹ A² + 3³ᵏ A³ = 0 です。k ≥ 1 では後ろの 2 項が 3ᵏ⁺² で割り切れるので、やはり A ≡ 0 (mod 3)。

どちらも A の選び方に反するので、g = I です。

したがって、GAP が生成元の 3 を法とする還元から計算する群は Γ と同型です。Γ の位数と、最初の 2 つの生成元が生成する部分群 S の位数は真の位数であり、S の同型類も真の同型類です。また −I ≢ I (mod 3) なので、−I ∈ S であることと、その還元が S の還元に属することは同値です。GAP は S によるあるベクトルの軌道をとり、S がその上に忠実に作用することを確かめ、得られた置換群を SL(2, 29) と比べます。この比較には GAP のパッケージ SmallGrp が必要です。

これで、配布した各格子について S を同定し、−I ∈ S を確かめたことになります。そのような作用をもつ*任意の*極値格子の上で −1 ∈ SL₂(29) が −1 として作用することは別の主張で、[STATUS.ja.md](../STATUS.ja.md#加群の型) の加群の型への絞り込みに含まれます。
