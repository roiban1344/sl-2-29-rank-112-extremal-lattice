# Data format (schema version 2)

`lattices/L112.XX/entry.toml` is the canonical metadata entry. `lattices/index.json` is an ordered array of the same entries, without loss of fields. Text is UTF-8. Gram matrices use row coefficients: the norm is x G xᵀ. Ignore `#` comment lines; the remaining 112 lines each contain 112 decimal integers.

- `schema_version`, `id`, `dimension`, `gram`, `generators`: format version, stable ID, rank, and local filenames of the Gram matrix and the generators.
- `witness_norm10`: local filename of a vector of norm 10 (L112.01–14). It bounds the minimum from above only.
- `group.generated_order`: the order of the group generated by all the matrices in `generators.txt`. It is not a claim that this group is the full automorphism group.
- `gram_sha256`: hash of the distributed Gram file.
- `properties`: exact checks of positive definiteness, evenness and determinant. The checker verifies these against the distributed integers.
- `claims.minimal_norm`: 10 for L112.01–14, a research claim rather than an output of the included checker. Omitted for L112.15, whose minimum is unknown. Its `claims` table is empty (an empty object in JSON).
- `independent_check`: a verification published by someone else, fixed to a commit (L112.02 only). It is cited, not checked by the included checker.

The table `extremality` says how the claimed minimum is known, in separate fields.

| Field | Value | Meaning |
|---|---|---|
| `method` | `computer-assisted` | A written reduction plus an exhaustive computation with rigorous error control |
| | `computed` | A computation that has not been accepted as a proof |
| | `open` | The minimum is unknown |
| `package` | `external` | The material for checking is in another repository, at `package_url` |
| | `included` | The material for checking is in this repository |
| | `not-included` | A minimum is claimed, and the material for checking it is not in a release yet |
| | `none` | No minimum is claimed, so there is nothing to check |
| `review` | `none` | No review of this statement by anyone other than its authors is recorded here |
| | `internal-ai` | AI sessions that did not write the material audited its steps. This is not human review, and an audit does not close the steps it found open |

No entry claims human review. `SHA256SUMS` covers every distributed file except itself. The checker refuses any file it does not list, and any release without the required files or with lattices other than these fifteen. Generated files in `out/` are not distributed. Distinct IDs do not certify pairwise non-isometry.

In `generators.txt`, each matrix follows a line `# generator: <label>`, and the labels of the first two begin with `SL_2(29)`. Matrices act on row vectors from the right, so that g G gᵀ = G. The labels other than `SL_2(29)` are descriptions and are not checked.
